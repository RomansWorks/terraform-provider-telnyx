## 0.1.0 (November 8, 2026)
First release. Every Telnyx API v2 operation is either implemented or recorded as out of scope in `catalog/coverage.yaml`: 164 resources, 438 data sources, 113 actions and 4 ephemeral resources. Requires Terraform 1.11 or later (1.14 for actions) or OpenTofu 1.11 or later (no actions). Acceptance tests have not yet run against a live Telnyx account, so treat 0.1.0 as a preview.

### NOTES
* Initial provider foundations: provider configuration, HTTP core with retries, pinned Telnyx API spec, operation coverage and the daily API sync. No resources yet.
* OpenTofu 1.11 or later is tested in CI and supported for everything except actions, which need Terraform 1.14. A new guide, "Terraform and OpenTofu", lists what works where ([#27](https://github.com/RomansWorks/terraform-provider-telnyx/issues/27))
* Every resource now has a usage example and an import example in its documentation.
* Builds with Go 1.26.10, with every Go dependency updated to its latest release.
